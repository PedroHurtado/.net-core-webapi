INSTRUCCIONES DE USO:

1. Crea una carpeta llamada "reservas-app"

2. Copia cada sección de arriba en archivos separados con los nombres indicados:
   - index.html
   - reserva-step1.html
   - reserva-step2.html
   - reserva-step3.html
   - reserva-step4.html
   - reserva-success.html
   - admin-dashboard.html
   - admin-schedule.html
   - admin-schedule-special.html
   - admin-services.html
   - admin-policy.html

3. Inicia un servidor HTTP en la carpeta:
   
   Opción A - Python:
   python -m http.server 8000
   
   Opción B - Node.js:
   npx http-server
   
   Opción C - PHP:
   php -S localhost:8000

4. Abre en el navegador:
   http://localhost:8000/index.html

5. Navega por los diferentes flujos usando los enlaces

FLUJOS DISPONIBLES:

Cliente:
index.html → reserva-step1.html → reserva-step2.html → reserva-step3.html → reserva-step4.html → reserva-success.html

Admin:
admin-dashboard.html → admin-schedule.html / admin-services.html / admin-policy.html

- Diseño minimalista y limpio
- 100% HTML + CSS (sin JavaScript)
- Responsive (funciona en mobile)
- Navegación mediante links
- Formularios visuales (no funcionales sin JS)
- Estados visuales de disponibilidad
- Código de colores intuitivo
